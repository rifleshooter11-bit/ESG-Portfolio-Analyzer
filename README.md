# Verdant Ledger — ESG website

A standalone, static ESG disclosure and enterprise valuation website.

## Publish free with Cloudflare Pages

1. Create a free Cloudflare account.
2. Go to **Workers & Pages** → **Create application** → **Get started** → **Drag and drop your files**.
3. Enter a project name, such as `verdant-ledger`.
4. Upload this folder's three website files: `index.html`, `styles.css`, and `app.js`.
5. Select **Deploy site**. Cloudflare provides a public `https://<project-name>.pages.dev` URL.

## Included

- SEBI BRSR Core and ISSB (IFRS S1/S2) reporting baseline
- Double materiality matrix
- Scope 1/2 and supplier Scope 3 ingestion path with normalisation evidence
- CEA electricity-factor disclosure placeholder and data-quality guardrails
- E/S/G score inputs, ESG CapEx/OpEx impacts, WACC adjustment and interactive DCF enterprise-value comparison
- Sealed, append-only evidence snapshot view and CSV export

The displayed figures are scenario demonstration values. Replace them with approved company data and applicable emission factors before investor or regulatory use.
